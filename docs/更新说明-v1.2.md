# 更新说明 v1.2.0

## 发布日期：2026-02-28

## 主要更新

### 1. 人物介绍页面重构 ✨

#### 新增功能

- **人物详情弹窗**
  - 点击人物卡片弹出详细信息
  - 精美的弹窗设计，渐变背景
  - 包含角色头像、名称、介绍
  - 详细信息、特殊能力列表
  - 经典语录展示

#### 交互优化

- 卡片点击触发弹窗
- 弹窗淡入淡出动画
- 关闭按钮旋转动画
- 防止背景滚动
- 响应式布局适配

#### 数据扩展

- 新增 3 个角色（咕咚、老板等）
- 每个角色添加详细信息
- 特殊能力列表
- 经典语录

### 2. 剧情介绍页面重构 📖

#### 时间线布局

- 采用垂直时间线设计
- 左右交替排列剧集
- 中间时间线连接
- 圆形标记显示集数

#### 内容优化

- 扩展到 6 话内容
- 每话包含：
  - 话数标签
  - 标题
  - 详细描述
  - 精彩看点列表

#### 视觉效果

- 卡片悬停效果
- 交错入场动画
- 渐变色时间线
- 发光标记圆圈
- 响应式布局

### 3. 组件新增

#### CharacterModal.vue

- 人物详情弹窗组件
- 支持自定义内容
- 优雅的动画效果
- 完善的样式设计

## 使用说明

### 查看人物详情

1. 进入人物介绍页面
2. 点击任意人物卡片
3. 查看详细信息
4. 点击关闭按钮或遮罩层关闭

### 浏览剧情时间线

1. 进入剧情介绍页面
2. 滚动查看时间线
3. 查看每话的详细信息
4. 了解精彩看点
